# 🌐 Diya Chanda — Portfolio

Welcome to my personal portfolio! This website serves as a digital showcase of my journey as a Computer Science student specializing in Artificial Intelligence and Machine Learning. It highlights my technical skills, academic projects, research work, achievements, and experiences in software development and AI.

Built with **React**, **Vite**, and **Tailwind CSS**, the portfolio features a modern, responsive, and user-friendly interface that provides a seamless experience across desktop and mobile devices.

## 🚀 Tech Stack

- React.js 19
- Vite
- Tailwind CSS
- Framer Motion
- JavaScript (ES6+)
- HTML5 & CSS3

## ✨ Features

- Modern, responsive dark-mode interface with smooth animations
- About Me & academic journey timeline
- Skills & technologies categorized by domain
- Featured machine learning & software engineering projects
- Research publications (IEEE conference papers)
- Verified certifications & awards lightbox viewer
- Interactive contact form with EmailJS integration

## 📂 Getting Started

1. Clone the repository and install dependencies:

```bash
git clone https://github.com/chandadiya2004/portfolio_diya.git
cd portfolio_diya/portfolio
npm install
```

2. (Optional) Configure environment variables for the contact form:
Copy `.env.example` to `.env` and fill in your EmailJS credentials:
```bash
cp .env.example .env
```

3. Start the local development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
