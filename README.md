# 🌐 My Portfolio

Welcome to my personal portfolio! This website serves as a digital showcase of my journey as a Computer Science student specializing in Artificial Intelligence and Machine Learning. It highlights my technical skills, academic projects, research work, achievements, and experiences in software development and AI.

Built with **React**, **Vite**, and **Tailwind CSS**, the portfolio features a modern, responsive, and user-friendly interface that provides a seamless experience across desktop and mobile devices. The website reflects my passion for creating clean, interactive, and performance-driven web applications.

## 🚀 Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- HTML5 & CSS3

## ✨ Features

- Modern and responsive design
- Interactive and intuitive user interface
- About Me section
- Skills and technologies
- Featured projects with descriptions
- Research publications and achievements
- Resume section
- Contact section
- Optimized for fast performance

## 📂 Getting Started

Clone the repository and install the dependencies:

```bash
git clone https://github.com/your-username/my-portfolio.git
cd my-portfolio
npm install
npm run dev
```

The development server will start locally, allowing you to explore and customize the portfolio.
